# 알려진 문제

## Phase 2.1 갱신

- TMDB_READ_ACCESS_TOKEN이 현재 실행 프로세스에 없다. live 조회는 종료 2, 30개 실시간 검증 미실행이다. 환경변수 설정이 필요하며 토큰은 채팅/파일에 제공하지 않는다.
- 로컬 PostgreSQL/Docker가 없다. 독립 CI PostgreSQL 16에서 실제 SQL 검증은 성공했다(22 assertion). 로컬 실행 및 운영 DB 적용은 하지 않았다.
- v0.2 매핑에 다른 작품 회차를 연결할 수 있고, future verified_at이 허용되는 결함을 실제 기준 버전 SQL에서 재현했다. migration_v0_2_1.sql 수정 후 거부 및 기존 기능 통과를 CI에서 확인했다. 운영 DB는 변경하지 않았으므로 적용 여부를 별도 결정해야 한다.
- 매핑은 같은 작품의 여러 정규 시즌을 아우를 수 있으나 실제 OTT 시즌/파트 대응의 진실성은 사람이 출처로 검증해야 한다. 합본/스페셜/더빙판 의미까지 DB가 자동 판정하지 않는다.
- 추가 마이그레이션은 기존 잘못된 데이터가 있으면 중단한다. 운영/기존 데이터 자동 정정·삭제는 하지 않는다. SQL 트리거의 다중 세션 경합 테스트는 이번 단일 세션 fixture 검사 범위 밖이다.
- API 오류/누락 처리는 모의 응답으로 확인했다. 실제 API 스키마 변화·KR 제공 정확성·현재 OTT 회차는 여전히 미확인이다.
- Python 신규 테스트는 CLI 분리 출력과 오류 회귀를 검증하고, 서버 응답 문자열 전체나 토큰을 로그에 기록하지 않는다.

## 보안 점검의 한계

`.gitignore`는 신규 파일의 기본 추적만 제외하며 이미 추적된 파일/과거 커밋의 비밀을 제거하지 않는다. `.env.example`은 값 없는 예시만 허용한다. 커밋 전 경로와 토큰 형식/환경변수 할당 패턴을 검사하더라도 모든 형식의 인증 정보를 검출한다고 보장할 수 없다. 이번 작업에서는 토큰 값/인증 파일을 업로드하지 않으며, API 토큰은 실행 환경변수로 사용한다.

과거 Phase 2 보고서의 Git 미연결 상태는 당시 기록으로 보존했다. 최신 저장소 상태는 DEVELOPMENT_STATUS.md를 따른다.
